## 4. ★ 체제(regime) 레버 (13, 18)
- 상황-only LGB 가 `season` 열 유무로 τ **+0.253 / −0.015** (13). 이유: 트리가 season≥2023 분기로 F 경기의 새 체제를 학습.
- `game_type` 2셀 표 하나로 τ **±0.257** — 최근 1시즌 표면 +, 2시즌 이상 평균이면 − (2022 F 가 너무 좋았음) (18-1).
- 투수 EB + cnt×gt 표: 최근 99시즌 τ 0.094 → 최근 2시즌 0.109 → **최근 1시즌 0.266** (18-2).

- F 비중 자체가 순위 신호: τ(−F비중, 실제pt) = +0.257. 신인 115명 중 32명, 이력 1–500 투수 91명 중 25명이 F 전용 (18-3).

- **LGB 에 `season` 열 하나 추가: τ 0.201 → 0.321, Total 66.98 → 68.81 (+1.8)** (19). regime 플래그(≥2023)는 0.289 로 season 열보다 못함 — 2022→2023 뿐 아니라 연도별 미세 변화도 쓰는 듯.
- 최근 2시즌(2022–23)만 학습 + season 열도 68.81 로 동일 → 옛 시즌은 이력 인코딩 재료로만 쓰면 되고 학습 행으로는 불필요.
- season 모형에서는 신인 τ 0.32 / 비신인 0.32 로 균등 (15A 는 0.27 / 0.21).
- 2025 추론 시 트리의 season=2025 는 '≥2024 분기' 로 떨어져 2024 와 같은 잎 → 외삽이 아니라 '최신 체제 유지' 와 동치.

## 5. Brier ↔ τ 트레이드오프 (16)
- τ 는 투수별 예측점수 평균의 **순위** 만 본다 → 모형 자체 신호를 k 배 키워도 τ 불변, Brier 만 악화 (16-1).
- 따라서 방법은 '더 좋은 투수 순위 신호 r 을 확률에 ε 만큼 섞기'. 종민 잔차EB(τ 0.248) 를 LGB(τ 0.201) 에 ε=0.02~0.04 섞으면 τ 0.25, **Total +0.7**, Brier 손실 0.001~0.003 (16-2).
- 신인 tie-break(li3×sd5 배치축, 종민 08) 추가는 +0.01 τ 수준.

## 6. 투수·타자 이력의 형태 (14, 15)
- 투수 EB α 는 Total 기준 200~500 (τ 는 작을수록, Brier 는 클수록). 최근성 반감기는 Brier 에 약간 좋고 τ 에 나쁨 (h=99 가 τ 최고).
- 투수×game_type 셀 EB 가 τ +0.015 (3폴드 평균 최고 0.216) — F/R 에서 다른 투수 성향.
- 타자 EB: Brier·τ 모두 거의 무효과(α 3000 에서나 중립). 팀 EB: 신인 대체 정보로 무효.
- LGB: pitcher_id 범주형 직접 투입은 과적합(τ 0.17). num_leaves 31~127 무차별. 최근성 인코딩(h=2) 추가 시 τ +0.02.
- LGB 는 신인끼리 τ +0.27 을 스스로 찾는다 (li·점수차·이닝 배치축, 종민 08 과 일치).

## 8. 모형 방향 (EDA 가 말하는 것)
1. **체제 인식이 1순위**: LGB 에 `season` 열 포함 (Total +1.8). 표 모형이면 game_type 효과는 최근 1시즌으로만.
2. 그 위에 투수×game_type EB + 최근성 h=2 인코딩, 시드/변형 앙상블(확률 평균) → Total 68.96. 추가 순위 신호(종민 잔차EB, Trackman 직구비중)는 ε≈0.02 주입으로 실험 (16).
3. Brier 는 카운트 + 직전 1~2시즌 prior + 투수 EB 로 끝. 과한 피처/튜닝은 무의미 (Pitch 상한 ~70.0).
4. 신인(평가 행 19.5%): LGB 배치축으로 τ 0.27 확보됨, 별도 처리 불필요. F 전용 신인은 체제 효과로 자연히 하위 랭크.
5. 검증은 반드시 2024 폴드 Total 로 (2023 폴드는 체제변화가 평가시즌 안에서 일어나 어떤 방법도 못 맞춤).
