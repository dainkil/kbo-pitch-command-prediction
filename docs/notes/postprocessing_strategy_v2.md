**결론: 이미 포화. 마지막 2시간에만, 상방 +0.03~0.05 Score.**

- 피처셋: d4형 **69 피처** 유지 (상황 23 + season + 투수 EB 3종 12 + p_skill + 투수×gt 3 + p_fshare/p_n_all + Trackman 19 + 좌표 7 + pgt_rev). noF 62 와의 LB Pitch 차 0.007 → 체제 피처 유무 무관. anchor 아래선 **Player 위험 0** 이므로 Pitch 에 좋은 건 다 넣어도 된다.
- **셀렉션 규칙**: 2024 폴드 **Pitch** 로만 판정 (이관 93%). Δ < 0.01 은 시드 잡음. Player 는 보지 않는다(anchor 가 지움).
- 후보 순서 (기대 Pitch): ① 시드 5→10 (+0.005) ② O8 all-P Trackman 프로필 (+0.01~0.03) ③ CatBoost/TabM 확률 블렌드 (+0.01~0.03) ④ **타자 키 프록시** — ABS 존은 타자 키 비례, 라벨 박스는 미터 고정 → 2024 R 행의 타자별 plate_loc_height 평균 표 (batter_id 조회, 행 독립). 미검 ⑤ 좌표 multi-task(위치 회귀 보조라벨) — 유사 피처 이미 있음.
- 하지 않을 것: pitcher_id 범주형(LGB 과적합 τ 0.17), 타자 EB(무효), GBDT 로 Player 노리기.

### 3-2. 셀렉션 규율
1. 축당 **기대 Δτ ≥ 0.01** 인 것만 제출 (n≈700, τ SE ≈ 0.025 → Player 0.05 차이는 무의미).
2. **단독 → 결합** 순. L31(팀+손) 이 단독 둘보다 낮았다. 결합은 단독 결과가 둘 다 양수일 때만.
3. 레짐 축(F·시즌·팀)은 **폴드로 고르지 않는다**. 추정량 축(α·기대순위)은 폴드 참고 가능.
4. LB 는 **A/B 선택**에만. γ 깊이 스캔은 3점 이하 (규칙 3: 평가면 역산 금지 경계).
5. d9 결과가 나오기 전엔 d-계열 결합 제출 금지 (기준선 없이 증분 못 잼).
