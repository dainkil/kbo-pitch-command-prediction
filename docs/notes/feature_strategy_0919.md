**결론 한 줄** — 남은 τ 는 "대이력 투수를 더 잘 재는 것"이 아니라 **소이력 투수의 순서**에서 나온다. 해외 정석(Robinson *beta-binomial regression prior*, Open Command 의 계층 EB)은 이 문제를 **"EB prior 의 평균을 공변량의 학습된 함수로 바꾸는 것"**으로 푼다. 우리 배치셀 prior(li×inn×sd)·L76(isF×z(log n))은 그 특수형이었다.

**4-3. ⚠ LB 교차 증거 — L76 (21:20)**: 종민의 `F 보정 × 이력크기` (소이력 F 행을 내림) 는 폴드 +5.92 → **LB −5.37**. 양쪽 부호 모두 해롭고 LB 최적은 g=0. 즉 **"F 행/F 이력을 소이력 투수의 실력 증거로 쓰는 것"은 LB 가 이미 기각**했다. Af 의 상위 gain 은 `p_fshare`(11.8%)·`game_type`(2.3%) — **같은 기계**다. Af 의 신인 +0.28 은 L76 의 폴드 +5.9 와 같은 종류의 폴드 착시일 확률이 높다.
→ **1순위 = Cf (F-blind)**: 구종 구성(`pk_mix`)·트랙맨 구성/구속·이력 크기·기용·타자 — LB 가 아직 한 번도 재보지 않은 정보만으로 소이력 순서를 매긴다. Af 는 "폴드는 좋다고 하고 LB 전례는 나쁘다고 하는" 탐침으로 1회.
