## 3. 방법 카탈로그 — Player(τ) 축

각 항목: 출처 → 왜 여기 맞나 → 행 독립 구현 → 이미 시도? → 리스크.

### 3-A. 검증면 재정의 (가장 싸고 가장 구조적)
- **출처**: Phase 2 상위 6%([minwoooo330](https://github.com/minwoooo330/lg-aimers-pitch-control)) — walk-forward 폴드의 평가행을 `(game_type=="R") | (season>=2023)` 로 제한, "2025 test 에 존재하는 행 유형만". 잡음 바닥(시드 재학습 SD)을 먼저 재고 그 이상만 채택.
- **여기서**: 우리 3폴드(2022·23·24)는 2022 F 행(옛 체제)을 평가면에 포함한다. 2022 폴드가 loc 주입·far50 등에서 유독 반대 부호를 낸 이유. **F 행은 2023+ 폴드에서만 평가**, 2022 폴드는 R 행만.
- **추가**: §1 대로면 2025 는 F 50투구+ 투수가 더 많다 → 폴드에서 **F 투수 가중 재표집**(F 비중 상위 투수를 2배 등)한 "2025-유사 표면"을 하나 더 만든다. 종민 "새 표면 5개"(시즌 내 전후반·격년)에 추가.
- **행 독립**: 검증 전용, 제출물 무관.
- **리스크**: 표면이 하나 더 늘어 승자의 저주(종민 §6) 재발 — 사전등록 게이트 필수.

### 3-B. 드리프트 인식 수축 — DLM/Kalman (지수가중의 올바른 판)
- **출처**: [THT "Regression with Changing Talent Levels"](https://tht.fangraphs.com/regression-with-changing-talent-levels-the-effects-of-variance/) — 실력이 시간에 따라 움직이면 회귀상수가 커져야 하고, `Var(d) = Var(0)·[1 − (1−r)²d/2]` 로 드리프트 상관 r 을 추정. [Tango 회귀상수](https://tangotiger.net/archives/stud0322.shtml) = 실력분산 = 운분산 되는 표본수.
- **여기서**: 종민 E08 — "이론 최적 α=434 인데 실측 꼭짓점 2000~4000 = 5~9배. 원인은 실력 드리프트". 즉 드리프트가 **정량적으로 크다.** 기각된 "최근성 가중"은 옛 표본을 **버려서** 손해였다. DLM 은 `θ_t = θ_{t−1} + η(σ²_drift)`, `ȳ_t ~ N(θ_t, σ²/n_t)` 로 **모든 시즌을 n_t 에 따라 자동 가중**하고 σ²_drift 는 데이터(시즌간 잔차 상관)에서 추정. 신인·소표본은 자동으로 prior 로 수축.
- **행 독립**: 투수별 표 (2025 예측 θ̂_2025) 하나 → `pitcher_id` 조회. anchor 목표로 그대로 사용.
- **이미 시도?**: 지수가중·Marcel·β 드리프트(α_eff=α+β·n) 는 기각. **DLM 형태는 미시도.** β 드리프트가 LB −0.0019 였으니 크기가 작을 수 있음 — 다만 σ²_drift 를 **레벨(F/R)별로** 따로 두면 §1 축과 결합됨.
- **리스크**: 시즌이 6개뿐이라 σ²_drift 추정이 거칠다. 격자 3개(작음/중간/큼)만.

### 3-C. 사후 기대순위 (posterior expected rank) 를 anchor 목표로
- **출처**: [Laird & Louis 1989](https://journals.sagepub.com/doi/10.3102/10769986014001029), [Shen & Louis 1998 triple-goal](https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/1467-9868.00135) — 순위가 목표면 최적 점추정은 사후평균이 아니라 **조건부 기대순위** `R̄_p = Σ_q P(θ_p > θ_q | data)`. 정밀도(n)가 다른 단위를 섞어 순위 매길 때 사후평균 순위와 달라진다. 최신: [Targeted EB Ranking (2025-11)](https://arxiv.org/abs/2511.16530) — 순위손실을 직접 최소화하는 α·회귀계수 추정.
- **여기서**: τ_b 가 정확히 순위손실. 지금 anchor 목표 t_p = EB 사후평균. 기대순위판: `t'_p = Φ-표(m_p, v_p)` — 학습 투수 집합 {(m_q, v_q)} 을 **고정 참조표**로 두고 `R̄_p = Σ_q Φ((m_p − m_q)/√(v_p+v_q))` 를 계산해 점수 스케일로 되돌린다(순위 → 참조 분포의 분위 점수). 소표본 투수가 **분포의 가운데 순위**로 가는 정도가 사후평균과 다르다(비대칭 분포에서 특히).
- **행 독립**: 참조표는 학습 투수만 → 표 조회.
- **이미 시도?**: 미시도. "Targeted" 판(α 를 next-season τ 로 고르기)은 3폴드로 이미 하고 있는 것과 동치.
- **리스크**: 크기가 작을 수 있음 (Δτ<0.01 이면 LB 로 검출 불가). 단 비용이 거의 0.

### 3-D. LB 사용 규율 — 재사용 홀드아웃
- **출처**: [Dwork et al. Reusable Holdout / Thresholdout](https://research.google/blog/the-reusable-holdout-preserving-validity-in-adaptive-data-analysis/), [Blum & Hardt "The Ladder"](https://proceedings.mlr.press/v37/blum15.pdf) — 임계값 이하의 개선은 갱신하지 않고, 적응적 질의 횟수를 제한.
- **여기서**: n≈700 투수에서 τ 의 SE ≈ √(2(2n+5)/(9n(n−1))) ≈ **0.025**. 개입 한 건의 Δτ 가 0.01 이면 잡음. 실측 표(β +0.0038→−0.0019, 대리채움 +0.0044→−0.0064)는 전부 이 안. **규율**: ① 한 축당 크기 ≥0.02 예상되는 것만 제출, ② A/B 를 같은 시각에 쌍으로, ③ Private=Public 이라 LB 과적합의 구조적 위험은 0 이지만 **선택 기준으로만**(공통규칙 1-LB).
- **1위는 53회 제출로 τ 0.33→0.40** — 큰 축을 찾아 반복한 것이지 미세조정이 아니다. 우리는 11회.

| [Location+ / PitchingBot Command](https://library.fangraphs.com/pitching/pitchingbot-pitch-modeling-primer/) | 카운트·구종별 위치의 기대 run value | 라벨이 이미 위치 등급이라 중복 | 불필요 |

- **공통 교훈**(Kirby): 해간 안정성이 높은 지표 = **기계적 일관성**. 우리 `tm_sd_rel_height` 등은 구종 혼합 때문에 안정성이 낮을 수 있다 → 구종·경기 내 분리 sd 로 재계산 후 **해간 자기상관**(2023→2024)부터 재는 것이 순서 (celine 문서 §6 우선순위와 결합).

### 3-F. 1군/2군 파이프라인 분리 (Phase 2 실전 사례)
- **출처**: Phase 2 180위 [wogho](https://github.com/wogho/LGAIMER_9th) — "1군/2군 Macro-Leap Decoupling", 분리로 F 예측 +3,172 BSS. 같은 팀 다른 참가자([minwoooo330](https://github.com/minwoooo330/lg-aimers-pitch-control)) 도 F 는 2023+ 만 사용.
- **여기서**: 우리는 game_type 을 **GBDT 피처**로 넣었다가 Player −2.38(종민)·d4 붕괴. 분리는 다른 것: **표(EB)를 gt 별로 따로** 만들고 행의 gt 로 조회 (seongmin 문서 §4.3 `r_{p,gt}` 와 동일). Pitch 쪽은 anchor 가 보호.
- **행 독립**: OK (행 자기 열 + 표).
- **이미 시도?**: 종민 L8(isF prior) 버그 → L8b 미기록. **L8b LB 를 먼저 읽는다.** dain `pgt_*` 는 GBDT 피처로만.
- **리스크**: 2025 F 표본이 과거 F 표와 다른 모집단(§1). F 표 α 를 크게.

### 3-G. 학습행 인샘플 오염의 정석 해법 (Pitch 쪽이지만 anchor 목표 표에도 해당)
- **CatBoost ordered target statistics** ([원리](https://towardsdatascience.com/how-catboost-encodes-categorical-variables-3866fb2ae640/)): pitcher_id 를 범주형으로 넣어도 자기 라벨을 안 쓴다. 종민 LOSO(+1.80) 를 손으로 한 것과 같은 목적. seongmin S1(CatBoost) 이 큐에 있음. dain 실측 "pitcher_id 범주형 직접 투입 과적합(τ 0.17)" 은 **LightGBM** 이야기.
- **GPBoost** ([Sigrist](https://github.com/fabsig/GPBoost)): LightGBM 트리 + **투수 랜덤효과**(수축량을 데이터가 추정). "EB 표 + GBDT" 를 한 모델에서 정합적으로. 제출은 `pip install gpboost` 필요(설치 오류는 횟수 미반영이라 시도 비용 낮음).
- **판정**: Pitch 포화라 총점 기여 ≤0.1. 앙상블 다양성용. 후순위.

### 3-H. 직접 순위 학습 (참고만)
- [DiffKendall](https://arxiv.org/abs/2307.15317) 등 미분가능 τ, LambdaRank. seongmin 문서 §6 의 판정 그대로: 투수-시즌 전이 표본이 5개 시즌뿐, Pitch 훼손 위험, 추론 시 행 독립 유지 어려움 → **작은 보조 모델**(이력 → 다음 시즌 점수, ridge/CatBoost) 에 한정. 종민 "투수-시즌 지도학습" 기각 · "소수 피처 Ridge" 기각. **재시도 가치 낮음.**

## 4. Pitch 축 (포화 — 기록만)
- 상위 10팀 Pitch 70.02~70.25, 우리 70.17. 남은 여지 ≤0.1 → 총점 ≤0.07.
- 유일하게 미시도이고 논리가 있는 것: **타자 키 프록시**. ABS 존은 타자 키 비례(상단 56%/하단 27%)인데 라벨 박스는 미터 고정 → 키 큰 타자에겐 같은 "존 상단 공략"이 Heart 가 아니라 Shadow/Failure 로 찍힌다. 2024 R 행(ABS 원년)에서 **타자별 plate_loc_height 평균**(타자 표) 을 만들면 2025(전 리그 ABS)에서 더 강해질 기하 신호. 행 독립 OK(batter_id 조회). dain "타자 EB 무효"는 등급비율 EB 였지 높이 표가 아님. 크기 작음 — 시간 남으면.
- 좌표 보조라벨 multi-task(위치 회귀 → 영역적분): seongmin O4 폴드 +0.4/+0.05/+0.14, 종민 "위치 모수 EB + 영역적분" Player 기각. Pitch 용으로만.

## 7. 우선순위 제안 (학습 없이 오늘 할 수 있는 순서)
1. **L14·L8b·d5·d6 LB 결과 읽기** → H1/H3 판정. F 레벨 축의 부호와 크기가 나오면 그 축으로 γ 를 한 번 더(크기 ≥0.02 예상 시).
2. **검증면 재정의**(§3-A): F 는 2023+, R 은 전체 + F-투수 가중 표면. 기존 후보(loc·far50·β)를 이 면으로 **재채점만** — 부호가 LB 와 맞게 바뀌면 검증면이 원인이었다는 증거.
3. **기대순위 anchor**(§3-C) 와 **DLM 수축**(§3-B) 을 표 생성 코드로 구현(학습 불필요, EB 표만 바뀜) → 2 의 새 면에서 크기 확인 → ≥0.02 면 쌍 제출.
4. Kirby 식 릴리스 일관성(구종·경기 내 sd) 의 **해간 자기상관**만 먼저 계산(§3-E) — 0.5 이상이면 anchor 목표 prior 후보.
5. Pitch 쪽(§4·§3-G)은 위 4개가 끝난 뒤.
