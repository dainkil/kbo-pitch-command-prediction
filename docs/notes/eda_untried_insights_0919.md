## 2. ★ 이력 구간별 '수준' 편향 — EB 는 소이력 투수를 2~4점 과대예측한다 (`eda/20, 21`)

EB(배치셀 prior, α=1300, adj 없음) 의 투수 평균 예측 − 실제 평균 (투수 ≥50구):

| 구간 | 2023 편향 | 2024 편향 | 2024 실제평균 | 2024 R행만 편향 | 구간내 τ (2024) |

- 전원 과대예측인 것은 **prior 수준이 낡았기 때문** (§2-c): 풀링 셀 prior 28.4~28.7 vs 최근 2시즌 27.2~27.9 vs 평가시즌 실제 27.1. 2019~22 의 높은 점수(F +6~+10 포함)가 prior 에 남아 있다.
- τ 에 중요한 건 **차등** 편향: 소이력(1~300) 이 베테랑보다 **~2점 더** 과대예측. 참 실력 sd 1.76 → 1 sd 가 넘는다. 이 구간의 τ 가 −0.02 인 이유.
- 편향의 원천 분해 (§2-a): **F 비중 >10% 인 투수에 집중** (2024 신인: F≤10% +0.94 / F>50% +4.62). 즉 대부분은 §0 의 "2023~24 F 수준" 현상 → 2025 에는 없을 가능성이 높다.
- **R 행만으로 채점해도 1~300 구간에 +3.0 (베테랑 +1.0) 남는다** — 이건 F 와 무관한 **"마진 투수 선택 효과"**: 몇 년째 100~300구만 던지는 투수는 R 에서도 리그보다 1.5점 나쁘다. 신인은 R 행에서 리그 평균(26.6 vs 26.5) — 신인은 나쁘지 않다, **"오래됐는데 소이력"이 나쁘다**.
- 오라클 δ (R 행만 채점): 1~300 구간 −1.5~−2.25 → τ **+0.023~+0.024** (2023/2024 둘 다). 전체 행이면 +0.037~+0.039 (F 성분 포함이라 2025 이관 의심).
- 누가 안 봤나: 종민 76번은 "이력크기 → 다음시즌, EB 통제 후 계수 −0.0088 ≈ 0" 이라 닫았다 — **선형** 항이었다. 실제는 비단조(신인 ≈ 리그, 1~300 최저, 이후 상승) 라 선형은 0 이 나온다. 종민의 "저이력 집단 배치 prior" 기각은 풀링(2019~22 F 높음) 데이터로 추정해 **반대 부호**였을 가능성.

| 목표 | R행 τ | 편향 신인 / 1~300 / 3001+ | 오라클 δ(1~300) → Δτ |

| base (α1300 + adj L25) | +0.290 | +1.80 / **+2.95** / +0.95 | −2.5 → **+0.029** |

| d15 = Af | +0.356 | +0.50 / +0.77 / +0.70 | −0.75 → +0.001 |

  **skill prior(Cf) 가 이 차등 편향을 이미 제거한다** (log n·구종·트랙맨으로 마진 투수 수준을 배움). δ 는 d10 위에서는 무효, **skill prior 를 안 쓸 때의 저비용 대안**(`t −= 2.5·[0<n≤300]`, 행 독립, R 행 기준 추정이라 F 노출 최소) 으로만 의미. 크기 Δτ +0.03 ≈ Player +1.5.

- ⚠ 단, 이 가중을 **배포 EB 목표에 그대로 얹으면 실패**한다 (24번: 베테랑 τ 0.53→0.31). EB 확률(수축·셀 prior)과 원시 비율의 스케일이 달라 이중 계산이 난다. 성분별 EB 를 따로 만들어 회귀 가중으로 합치는 형태(ws·EB_sh + wh·EB_he − κ·EB_rev, 가중은 폴드 표본외로)가 맞는 구현이고 **미시도**. 크기 기대 Δτ +0.01~0.03.
